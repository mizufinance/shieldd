# Circuit Soundness Findings

| ID | Severity | Finding | Evidence | Required mitigation | Status |
| --- | --- | --- | --- | --- | --- |
| `ZK-FIND-GO-UNREGULATED-NONMEMBERSHIP` | High | Go transfer and shielded ICS-20 circuits do not prove asset IMT non-membership on the unregulated branch. Rust proves membership or gap via `is_regulated.select(is_exact_match, is_in_gap)`, but Go uses `AssertEqualIf` and is vacuous when `IsRegulated=false`. | Rust `verify_asset_registry_imt` lines 797-815; Go `transfer_circuit.go` line 256 and `shielded_ics20_withdrawal_circuit.go` line 170. | Resolved: Go `VerifyAssetRegistryIMT` mirrors Rust via `Select(IsRegulated, isExactMatch, isInGap)` through AssetRegistryGap in both circuits; `transfer_metamorphic_test.go` rejects a regulated asset routed through the unregulated branch. | `resolved` |
| `ZK-FIND-WITHDRAWAL-EFFECT-HASH-EXTERNAL` | Medium | `WithdrawalEffectHash` is sound only if verifier extraction is the sole public-input source. The circuit consumes limbs; it does not derive the effect hash from the withdrawal action. | Go fields `WithdrawalEffectHashLo/Hi`; Rust `shielded_ics20_withdrawal_extract_public` derives limbs from `action.body.withdrawal.effect_hash()`. | Keep extraction centralized and add tests that mutated withdrawal body/effect limbs fail verification. | `accepted-risk` |
| `ZK-FIND-DUMMY-NULLIFIER-DOMAIN` | Low | Dummy nullifiers rely on domain-separated synthetic seeds; the argument is documented and tested but not formalized. | `NoteReshapePadder::synthetic_dummy_nullifier`; shielded withdrawal and transfer plans use separate labels. | Add an explicit lemma or finite-domain collision argument for dummy-vs-real nullifier separation. | `accepted-risk` |
| `ZK-FIND-RUST-GO-FIELD-CORRESPONDENCE` | Medium | Before this phase, the Go ABI only length-checked `StatementFields`; stored fields were not evidence that Go reconstructed the same vector as Rust. | `assignment_transfer.go`, `assignment_note_reshape.go`, and `assignment_shielded_ics20_withdrawal.go` check length. New `statement_fields_test.go` compares reconstructed Go vectors to Rust fixtures. | Keep the differential test gated and follow up with full hax/F* injectivity for Rust encoders (field-count injectivity is already proved). | `accepted-risk` |
