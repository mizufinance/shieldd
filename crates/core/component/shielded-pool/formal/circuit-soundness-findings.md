| `ZK-FIND-GO-UNREGULATED-NONMEMBERSHIP` | High | Go transfer and shielded ICS-20 circuits do not prove asset IMT non-membership on the unregulated branch. Rust proves membership or gap via `is_regulated.select(is_exact_match, is_in_gap)`, but Go uses `AssertEqualIf` and is vacuous when `IsRegulated=false`. | Rust `verify_asset_registry_imt` lines 797-815; Go `transfer_circuit.go` line 256 and `shielded_ics20_withdrawal_circuit.go` line 170. | Resolved: Go `VerifyAssetRegistryIMT` mirrors Rust via `Select(IsRegulated, isExactMatch, isInGap)` through AssetRegistryGap in both circuits; `transfer_metamorphic_test.go` rejects a regulated asset routed through the unregulated branch. | `resolved` |
| `ZK-FIND-WITHDRAWAL-EFFECT-HASH-EXTERNAL` | High | The old two-field encoding reduced two 256-bit halves modulo Fq and was not injective. | Rust now splits the 64-byte action effect hash into four 128-bit limbs; Go consumes all four under the version-2 statement domain. Rust/Go differential and semantic-mutation tests cover the exact order. | Resolved by the byte-injective limb encoding and domain/witness version bumps. | `resolved` |
| `ZK-FIND-DUMMY-NULLIFIER-DOMAIN` | Low | Dummy nullifiers rely on domain-separated synthetic seeds; the argument is documented and tested but not formalized. | `NoteReshapePadder::synthetic_dummy_nullifier`; shielded withdrawal and transfer plans use separate labels. | Add an explicit lemma or finite-domain collision argument for dummy-vs-real nullifier separation. | `accepted-risk` |
| `ZK-FIND-RUST-GO-FIELD-CORRESPONDENCE` | Medium | The Go ABI only length-checked a serialized `StatementFields` copy, which did not constrain the assignment and could differ without changing the proof. | Transfer and withdrawal no longer serialize the duplicate vector. Go reconstructs every statement field from the actual assignment inputs, hashes them natively, and requires the result to equal Rust's claimed hash; NoteReshape has the same reconstructed-hash differential. | Resolved at the deployed language seam. Full source-level encoder injectivity remains tracked separately from this concrete correspondence check. | `resolved` |
| `ZK-FIND-PROOF-BOUND-EFFECT-FILTERING` | Critical | Transfer and withdrawal handlers used unproved encrypted-body sentinels to suppress proof-bound nullifier and output writes, allowing a real nullifier to remain reusable. | All fixed-shape handlers now call `execute_proof_bound_effects`; serial/parallel projections, fee funding, FMD clue counts, and plans include every proof-bound slot. | `ZK-FIND-PROOF-BOUND-EFFECT-ATOMICITY` | High | A check-all-then-nullify-one-at-a-time implementation could discover a duplicate input only after staging the first nullifier, relying on outer transaction rollback for safety. | `execute_proof_bound_effects` now calls the SCT's duplicate-checking `nullify_all` once; the duplicate regression asserts rejection before any pending nullifier is staged. | Resolved by making proof-bound nullifier insertion an atomic batch operation. | `resolved` |
| `ZK-FIND-WITHDRAWAL-TRANSMISSION-BINDING` | Critical | Withdrawal spends and change commitments accepted a scalar transmission encoding unrelated to the DTK-bound affine transmission point. | Shared withdrawal context now compresses the DTK-bound sender point once and constrains every spend/change `TransmissionKeyS` to it. | `ZK-FIND-PROOF-ENCODING-CANONICAL` | High | Transfer, NoteReshape, and withdrawal proof decoders accepted variable-length or non-canonical Arkworks encodings. | The shared decoder requires exactly 192 bytes, consumes the full input, and requires canonical compressed reserialization. | `ZK-FIND-TRANSFER-FALSE-CERTIFICATION` | Critical | Transfer was labelled whole-circuit/full even though its abstract theorem and handwritten wiring snapshot did not refine the current deployed relation into independent protocol semantics. | The false stamp/inventory, stale generated contracts/reports, abstract Transfer theorem, and handwritten wiring snapshot were deleted. | `ZK-FIND-PADDED-AUTH-HASH-BINDING` | High | NoteReshape padded-slot signatures were derived over the action-body hash, while stateless verification checks every slot against the transaction effect hash. | `ZK-FIND-FV-PROMOTION-FAIL-OPEN` | Critical | The profile catalog could label an unsupported circuit `certified` using an existing Lean path and hand-authored zero-counter report, removing it from the candidate workflow without adding it to the exact Lean backend. | `check-fv-profiles.py` now requires the complete circuit registry, exact kind/shape, a fixed backend theorem and canonical coverage root for each certifiable NoteReshape family, null theorem/coverage roots for candidates, and parity between the certified catalog and `check-lean-circuit-fv.sh`. | `ZK-FIND-COMPLIANCE-POSITION-ALIAS` | Medium | Compliance quad-path verification decomposed a 64-bit position but consumed only the low 32 path bits, allowing multiple non-canonical witness positions to authenticate the same leaf path. | `VerifyQuadPath` now decomposes exactly `2 * ComplianceQuadTreeDepth` bits. | `ZK-FIND-FV-APPLICABILITY-GAP` | High | The formal workflow classified shielded-pool and gnark changes but could skip transaction authorization, app consensus execution, and view-side plan construction even though all three participate in the circuit soundness postcondition. | The gate now includes the local package closures for transaction, app, and view plus explicit action-handler, transaction-extraction, and wallet-planner paths. | `ZK-FIND-REQUIRED-SLOT-DUMMY-SURFACE` | High | Transfer and withdrawal modeled every fixed input with a dummy selector even though protocol construction requires at least one real spend. | `ZK-FIND-DUPLICATE-ADDRESS-WITNESSES` | Medium | Spend, receiver, and change records repeated sender/recipient affine and compressed address representations already present in shared context. | `ZK-FIND-WITNESS-ABI-MALLEABILITY` | Medium | The binary ABI admitted multiple byte encodings of one circuit assignment: non-boolean bytes, short paths that were zero-padded, field values reduced modulo Fq, noncanonical Fr scalars, oversized withdrawal limbs, and ignored duplicate statement/balance/indexed-key fields. | `ZK-FIND-HIDDEN-ARITY-SENTINELS` | Medium | Fixed-shape padding used empty encrypted backreferences and all-zero wrapped keys, publicly revealing which Transfer, withdrawal, and NoteReshape slots were synthetic despite the hidden-arity design. | Synthetic inputs now carry ordinary fixed-length encrypted backreferences; synthetic outputs use ordinary note/memo-key encryption. | `ZK-FIND-UNAUTHENTICATED-ACTION-API` | Low | Planner methods named `transfer`/`shielded_ics20_withdrawal` returned fixed-shape actions with placeholder padded signatures that cannot pass stateless authorization until transaction assembly replaces them. | These constructors are explicitly named `build_unauth_*`; transaction assembly remains the only completion point for padded signatures over the final transaction effect hash.
