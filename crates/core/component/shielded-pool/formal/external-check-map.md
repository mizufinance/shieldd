# External Check Map

Acceptance obligations here are enforced outside the arithmetic circuit.
“Composed” means the handwritten acceptance refinement requires the named fact
and the runtime has a corresponding enforcement path; it does not move that
runtime path into the circuit. Wallet-only rows are explicitly marked as
construction premises and are absent from `ConsensusAccepted`.
