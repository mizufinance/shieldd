# ZK Circuit Soundness Properties

The property rows describe the required proof architecture. The current V5
NoteReshape, V18 Transfer, and V10 Withdrawal artifacts are `candidate` profiles
pending recertification of their history-classification constraints; a row
marked `refined` is not by itself a certification of those candidate artifacts.

| `NO-DOUBLE-SPEND` | transfer, NoteReshape, shielded ICS-20 withdrawal | Each real input nullifier is uniquely determined by `(NK, commitment, position)` and the commitment path reaches the public anchor. Every dummy nullifier uses a family/slot-separated synthetic derivation; synthetic/real noncollision is computational under `ZK-ASSUME-SYNTHETIC-NULLIFIER-CROSS-DOMAIN-CR`, not an unconditional range-disjointness theorem. | `Nullifier`; `VerifyStateCommitmentPath`; real/dummy mux and synthetic-seed relations; exact `history_required = is_real && position < recent_position_floor` classification in every family. | Consensus checks both live nullifier generations for every slot. | `BALANCE-CONSERVATION` | all circuit families | Input amounts minus output/withdrawal amounts equal the constrained balance commitment for the one circuit-bound asset. | NoteReshape/Withdrawal conservation-specific balance ladders; Transfer net-balance ladder; amount bounds; NoteReshape claimed-point on-curve/equivalence; exact statement compression. | `NOTE-OWNERSHIP-SPEND-AUTH` | all spend circuits | Every real input binds `RK = AK + r*G`, its note address derives from the shared IVK, and its authorization signature binds the transaction effect hash.
