# Optimized desktop round evidence

The completed circuit, checked-loader and same-key polynomial matrix is documented in [the report](../../../../docs/research/transfer-proving-optimized.md). The broader campaign remains active.

This checkpoint saves raw measurements, correctness records, exact source archives and resource/test logs. `delivery.json` binds each copied file and the report/plots. Source manifests bind development keys, logical witnesses, assignments and executables retained in the ignored cache; these generated artifacts are not added to Git. Failed native control timings are retained for diagnosis and excluded from the comparison.

Three warmups and five measured warm proofs plus one fresh-process first proof per backend: all 27 proofs verified with unique bytes. Six correctness scenarios precede timing. Desktop ARM results are not physical-phone or verification-throughput measurements. Production release-gated suites and formal certification were not run.
