# Owned Pari377 arithmetic admission

Isolated desktop experiment using the same prepared subset key and proof protocol. The checked Rust loader admits the key and exact relation before an owned private Go child receives streamed canonical points. General file loaders remain unchanged. See `docs/research/pari-owned-admission-design.md` for the trust boundary, explicit states and required gates.

This candidate is not selected until exact reference proof/MSM parity, six full API gates, admission failure tests and a targeted startup/memory comparison pass. Its private child is not a standalone key validator or a phone backend.
