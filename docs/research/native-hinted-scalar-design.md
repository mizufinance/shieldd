# Corrected hinted Jubjub multiplication

This development screen targets variable-base 252-bit multiplications in the native BLS12-381 Transfer experiment. It preserves exact Jubjub coordinates, the existing canonical scalar checks, input subgroup checks and all downstream statement fields. The 129-bit balance multiplications and precomputed fixed-base ladders are unchanged. No production acceptance path is modified.

The host computes a dimension-two integer fraction using half extended Euclid: `s·v ≡ u (mod q)`, with nonnegative `u`, signed `v`, and both magnitudes below the square root of the prime subgroup order. The circuit permits conservative 128-bit magnitudes. This is the integer method, with no assumed Jubjub endomorphism. [Technique, section 2.5](https://eprint.iacr.org/2025/933)

Write `a=|v|`, and let the Boolean sign indicate negative `v`. The circuit checks `s·a=u+k·q` for positive `v`, or `s·a+u=k·q` for negative `v`. It bounds `u`, `a` and nonnegative `k` to 128 bits and requires `a≠0`. Since `2^128<q`, the denominator is nonzero modulo `q`. For scalar zero, the host supplies `u=0`, `a=1`, `k=0` and the identity output.

The congruence is an integer relation, not a single equality in the circuit field. Six base-2^64 limb equations compare the products. The five internal signed carries use the encoding `t=c+2^66`, with `t` constrained to 67 bits. Initial and terminal carries are zero. Every equation has a conservative absolute residual bound below `2^132`, far below the native field modulus, so its field equality is an integer equality. Summing the weighted equations cancels all internal carries and establishes the complete product equality. A test constructs an equality that wraps by exactly the native field modulus while keeping the short operands in range; the limb constraints reject it.

The hinted output `Q` requires an on-curve preimage `S` satisfying `[8]S=Q`. Three complete doublings establish prime-subgroup membership. This implements the full-cofactor correction; an even denominator can otherwise annihilate a torsion component and leave a wrong output accepted. The adversarial test explicitly verifies that its altered output satisfies the unbound native MSM before requiring the corrected circuit to reject it. [Cofactor correction](https://eprint.iacr.org/2026/1776)

For the joint check, set `R=-Q` for positive `v` and `R=Q` otherwise, so the desired relation is `uP+aR=0`. Precompute `U=P+R` and `V=P-R`. Start the accumulator at `U`. At each paired bit, double it and add one of `U,V,-V,-U`, selected by the two Boolean bits. Their XOR determines the unsigned point, and the numerator bit determines its sign. After all 128 positions, the accumulator is `U+2(uP+aR)`. Assert equality to `U`. Every point is in the odd-order prime subgroup, so multiplication by two is injective. The XOR is computed as `u+a-2ua`, with no unconstrained selector hint.

Addition and doubling use the already selected complete affine Jubjub formulas. Completeness follows from the validated input points and Jubjub's square `a=-1` and nonsquare `d`; selected points and all subsequent group operations remain on curve. The scalar relation and invertible denominator then establish `Q=[s]P` for every canonical scalar, including zero.

Full Transfer integration changes only the authorization, audit-encryption and recovery call sites. Authorization bases come from the sender compliance leaf; recovery and user audit keys come from the sender/receiver compliance leaves. Those points receive unconditional cofactor-preimage checks. Issuer keys select between the subgroup-checked asset-registry key and a fixed cofactor-cleared generator. Boolean key selection preserves subgroup membership. Authorization retains bounded scalar reduction; audit and recovery retain canonical subgroup-scalar decomposition. Hints are computed from current circuit values during witness construction, including EEA, output multiplication and preimage generation.

The three isolated call-site files preserve the original modules except for the multiplication calls. Other native modules are included from the retained source. The runner checks the old control's exact relation digest and both variants' original and converted assignments, statements and witness identities. It generates no key or proof. This is an algebraic argument with executable negative tests, not formal certification.

The same shortcut is not yet established for A/B's Decaf representatives. Preserving their exact coordinates requires following quotient representatives and torsion components through each consumer. A prime-subgroup replacement alone would be an unsupported semantic change.
